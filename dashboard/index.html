Sokongan Mobile & Desktop PWA

Aplikasi ini direka menggunakan seni bina Progressive Web App (PWA) yang responsif sepenuhnya dan menyimpan cache data terakhir secara pintar untuk rujukan pantas.

Cara Pasang ke Skrin Utama (Home Screen):
iOS (Safari): Tekan ikon Share di bawah pelayar dan pilih "Add to Home Screen".
Android (Chrome): Tekan menu 3 titik di penjuru atas dan pilih "Install App / Add to Home Screen".
